🎓 Marks & Grade Calculator (Java)

📌 About The Project

The Marks & Grade Calculator is a console-based Java application developed as part of a Data Structures and Algorithms (DSA) project. It helps calculate a student's total marks, percentage, and grade across five subjects.

This project demonstrates the practical implementation of core Java concepts such as Arrays, Loops, Methods, Selection Sorting, Linear Searching, and File Handling.

It also includes input validation to prevent invalid marks and file handling to save student records for future use.

✨ Features

📝 Enter Student Details: Input student name and marks in five subjects.

🧮 Calculate Total Marks: Automatically calculates total marks out of 500.

📊 Percentage Calculation: Calculates the overall percentage.

🏆 Grade Generation: Automatically assigns grades based on percentage.

🔝 Highest & Lowest Marks: Identifies the highest and lowest scoring subjects.

🔄 Sorting: Sorts marks in descending order using Selection Sort.

🔍 Searching: Searches for a particular mark using Linear Search.

⚠️ Input Validation: Rejects marks outside the 0–100 range.

💾 File Handling: Saves and loads student data using marks.txt.
